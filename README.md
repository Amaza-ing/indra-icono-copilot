# Estudio Norte!!!!!!

Landing page sencilla para una agencia creativa llamada Estudio Norte.

## Descripción

Este proyecto es una web estática de presentación con estilo editorial y minimalista. Incluye una estructura de landing page con:

- header con navegación
- hero section
- servicios
- sección sobre el estudio
- contacto
- footer

## Archivos principales

- `index.html` — estructura de la página
- `styles.css` — estilos visuales y diseño responsive
- `script.js` — lógica de la página (por ejemplo, reloj analógico y menú móvil)

## Cómo abrir la web

Puedes abrir directamente `index.html` en tu navegador o servir la carpeta localmente con un servidor simple, por ejemplo:

```bash
python -m http.server 8000
```

Luego visita:

```text
http://localhost:8000
```

## Personalización

Puedes cambiar:

- textos y contenido en `index.html`
- colores, tipografías y layout en `styles.css`
- comportamientos adicionales en `script.js`

## Tecnologías

- HTML5
- CSS3
- JavaScript
